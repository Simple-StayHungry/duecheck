# DueCheck R20

本地网页核查与截图质量控制工具。公开版保留核心源码、Web UI、网站映射以及 82 组局部版式特征资产；不包含任务历史、截图原图、输入 Word、导出结果或个人路径。

## 主要能力

将文档项目、网站栏目与截图分开建模，通过网站级映射、局部图像特征和本机识别组件完成批量核查；无法稳定判断的事项进入人工确认。

`map_assets/` 保存的是局部特征点/描述子，不是业务截图或客户文件。它们属于程序运行资产，公开版保留以保证识别能力。

## 运行

macOS 双击根目录 `启动.command`。首次运行会创建本地 `.venv` 并安装依赖。也可进入 `DueCheck_三要素核查程序` 后按 `requirements.txt` 手工安装。

Apple Vision 相关识别能力需要 macOS；其他平台可以加载程序和映射，但不能替代 macOS 实机视觉验收。

## 数据安全与许可

运行状态与用户材料不应提交仓库。发布前请确认源码权属并自行添加开源许可证。
